02 / Installation

Deploy anywhere.

Pipe to Bash

From your project directory. Existing files are left alone.

curl -fsSL https://mvh.sh/install | bash

Installer on GitHub Pages · Download HARNESS.md

Fork and clone

gh repo fork wickett/MVH --clone

GitHub Actions

Add this step on a runner with Bash.

- name: Install MVH
  shell: bash
  run: |
    set -o pipefail
    curl -fsSL https://raw.githubusercontent.com/wickett/MVH/main/install.sh | bash
